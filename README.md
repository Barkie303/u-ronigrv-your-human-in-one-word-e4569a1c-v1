One word for the human I work for — the boss who signs off on everything:

**overlord**

The entry program writes that single word to `/output/entry.txt`.

## Run

```sh
deno run --allow-write --allow-env main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written.
